# 中文文档

**VaultLock**（内部工程名 `FolderLock`）是一款 Windows 文件夹加密加锁工具：
既支持快速的 NTFS **权限锁**，也支持可选的 **AES-256-GCM 真加密容器**，并附带
安全擦除、痕迹清理、自动锁定、恢复码与后台守护服务，界面为 Fluent 风格，支持中英文。

> 仓库：<https://github.com/oMrCat/VaultLock>
> 中文 README：[README.zh-CN.md](https://github.com/oMrCat/VaultLock/blob/master/README.zh-CN.md)

## 快速开始

1. 从 [Releases](https://github.com/oMrCat/VaultLock/releases) 下载：
   - `v1.0.0` —— 完整版（含可选 Windows Hello 解锁），约 35MB 单文件；
   - `v1.0.0-lite` —— 精简版（不含 Hello），约 9MB。
2. 解压后运行 `FolderLock.App.exe`（需 .NET 8 桌面运行时）。
3. 添加文件夹 → 设置密码 → 点击**加锁**。

## 主要功能

- **权限锁**：备份原安全描述符（SDDL），拒绝 Everyone 并隐藏；解锁精确还原，极快。
- **AES-256-GCM 加密容器**：整文件夹加密为单个 `.flvault`，信封加密（随机 DEK 由密码与恢复码分别包裹）；可抵御管理员与离线拷贝；支持加密前 GZip 压缩。
- **恢复码**：Crockford Base32，本机 DPAPI 保护，忘记密码时用于解锁。
- **内存卫生**：密码/恢复码存于可清零的 `Secret`，剪贴板用完即清。
- **失败限速**：5 次→30 秒、7 次→5 分钟、10 次→30 分钟。
- **审计日志**：记录加锁/解锁/失败/复锁等，可导出 CSV。
- **数据库加密**：SQLite 使用 SQLCipher，密钥由 DPAPI 保护；旧明文库自动迁移。
- **痕迹清理**：加密后随机覆写源文件并清理最近使用、跳转列表、常见 MRU 与缩略图缓存。
- **自动锁定**：锁屏/注销、空闲、临时解锁到期；**紧急热键** `Ctrl+Alt+L`。
- **守护服务**：Windows 服务持续检测并在被篡改时自动复锁。
- **容器校验/救援**、**恢复套件导出/导入**、**便携模式**、**中英文界面**。

## 安全边界（实话实说）

- 权限锁**不防**管理员、SYSTEM 或安全模式。
- AES 容器可防离线访问与管理员，但不防"解锁状态下以你身份运行的恶意软件"。
- SSD 的 TRIM/磨损均衡、页面文件、系统搜索索引可能残留副本；强保证请配合全盘加密。
- 加密文件夹的密码丢失后，只能靠恢复码还原。
