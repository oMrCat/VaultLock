# 中文文档

**VaultLock**（内部工程名 `FolderLock`）是一款 Windows 文件夹加密加锁工具：
既支持快速的 NTFS **权限锁**，也支持可选的 **AES-256-GCM 真加密容器**，并附带
安全擦除、痕迹清理、自动锁定、恢复码与后台守护服务，界面为 Fluent 风格，支持中英文。

> 仓库：<https://github.com/oMrCat/VaultLock>
> 中文 README：[README.zh-CN.md](https://github.com/oMrCat/VaultLock/blob/master/README.zh-CN.md)

## 快速开始

1. 从 [Releases](https://github.com/oMrCat/VaultLock/releases) 下载：
   - `VaultLock-win-x64-unsigned-20261105.zip` —— 完整版（含可选 Windows Hello 解锁），约 11.7MB；
   - `VaultLock-lite-nohello-win-x64-unsigned-20261105.zip` —— 精简版（不含 Hello），约 5.6MB。
   两者均未签名，首次运行可能触发 SmartScreen 提示。
2. 解压后运行 `FolderLock.App.exe`（需 .NET 8 桌面运行时）。
3. 添加文件夹 → 设置密码 → 点击**加锁**。

## 主要功能

- **权限锁**：备份原 DACL（SDDL），拒绝 Everyone 并隐藏；解锁重新应用备份的 DACL（并非逐字节回滚），所有权被接管时需用 `takeown` + `icacls` 手动恢复。
- **AES-256-GCM 加密容器**：整文件夹加密为单个 `.flvault`，信封加密（随机 DEK 由 1~8 个密钥槽分别包裹：密码、恢复码、应急密码、本机 DPAPI）；可抵御管理员与离线拷贝；支持加密前 GZip 压缩。新容器为 **v3**（A/B 双头部块 + 认证结束块，可检测元数据篡改与截断）；**v2** 只读并支持就地升级为 v3（原文件保留为 `.bak`）；**v1** 仅可读。
- **恢复码**：Crockford Base32，本机 DPAPI 保护，忘记密码时用于解锁；支持打印、复制后自动清空剪贴板，创建或最后一次查看后 7 天内可免密码再次查看，创建后 30 天仍未确认已备份会在状态栏提醒。
- **多通道恢复**：密码之外的恢复码、应急密码、本机自动解锁（DPAPI）可各自独立解锁；“忘记密码”向导逐通道给出“通道不存在 / 密钥错误 / 成功”的明确结论。
- **密码提示**：DPAPI 保护的本机提示，仅写入本地数据库，不进入容器。
- **内存卫生**：密码/恢复码存于可清零的 `Secret`，剪贴板用完即清。
- **失败限速**：5 次→30 秒、7 次→5 分钟、10 次→30 分钟。
- **审计日志**：记录加锁/解锁/失败/复锁等，可导出 CSV。
- **数据库加密**：SQLite 使用 SQLCipher，密钥由 DPAPI 保护；旧明文库自动迁移。
- **痕迹清理**：加密后随机覆写源文件，并清理最近使用、跳转列表与常见 MRU；共享缩略图/图标缓存仅在开启 `CleanExplorerCaches` 时清理（默认关闭）。
- **自动锁定**：锁屏/注销、空闲、临时解锁到期；未缓存密码时不会自动重锁，会提示手动锁定；**紧急热键** `Ctrl+Alt+L`。
- **守护服务**：以 `NT AUTHORITY\LocalService` 运行，持续检测并在被篡改时自动复锁；签名校验默认**警告模式**（只写 `service.log`、不阻止启动），`FOLDERLOCK_REQUIRE_SIGNATURE=1` 才严格，当前发布包未签名。
- **容器校验/救援**、**恢复套件导出/导入**、**便携模式**、**中英文界面**；资源管理器右键菜单级联（文件夹：加锁/解锁/加入列表/移出列表/打开；`.flvault`：验证/解密/抢救/打开），默认写入 HKCU，支持多选。

## 安全边界（实话实说）

- 权限锁**不防**管理员、SYSTEM 或安全模式。
- AES 容器可防离线访问与管理员，但不防"解锁状态下以你身份运行的恶意软件"。
- SSD 的 TRIM/磨损均衡、页面文件、系统搜索索引可能残留副本；强保证请配合全盘加密。
- 加密文件夹的密码丢失后，可依靠恢复码、应急密码或本机自动解锁（DPAPI）等通道还原；任一通道可独立解锁，无后门。
